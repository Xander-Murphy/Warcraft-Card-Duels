# User Manual

## Heroic Encounters

A turn-based RPG where players build a team of heroes and battle enemies through increasingly difficult encounters.

## Requirements

Before running the game, make sure you have:

* Python 3.x
* uv
* Pygame

## Installation

1. Clone or download the project repository.
2. Open a terminal in the project directory.
3. Create the virtual environment:

```bash
uv venv
```

4. Install Pygame:

```bash
uv add pygame
```

## Running the Game

Run the game using:

```bash
uv run src/game.py
```

## How to Play

1. Start the game.
2. Select your team of 3 heroes.
3. Enter combat against the enemy team.
4. Choose actions for your heroes during their turns.
5. Defeat all enemies to win the encounter.
6. Continue through encounters and face increasingly difficult enemies and bosses.
